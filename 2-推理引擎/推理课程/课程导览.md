**导航**

从一次 GPU Kernel，到一套可测量、可诊断、可优化、可回归的 AI 系统。本课程面向有 Python 基础的学习者，系统打通 GPU 架构、CUDA、分布式训练、PyTorch Runtime 与 LLM 推理优化。

## 课程全景

- 28 课系统课程：从性能工程方法论一路深入到现代 LLM 推理系统。
- 8 个综合项目：每个项目都对应一个可运行、可测量、可展示的工程成果。
- 6 大核心模块：覆盖 GPU、CUDA、分布式训练、Compiler、Runtime 与推理系统。
- Level 0—2 分层实验：兼顾 CPU 通用验证、常见 NVIDIA GPU 和架构专项硬件。

## 这门课解决什么问题

- 看得懂：建立 Latency、Throughput、MFU、Roofline 与系统瓶颈的统一语言。
- 测得准：从 PyTorch Profiler、Nsight 到 GPU、通信和 Runtime 全链路定位。
- 优化得动：覆盖 Memory、Kernel、NCCL、FSDP、torch.compile、KV Cache 与调度。
- 交付得出：用可运行实验、Benchmark、回归门禁和系统设计完成工程闭环。

## 你将建立的完整能力栈

- 性能建模：把“感觉慢”拆解成计算、访存、通信、调度与 I/O 问题。
- GPU 与算子：理解 Warp、Memory Coalescing、Tensor Core、Kernel Fusion 与 Triton。
- 训练系统：掌握并行策略、NCCL、FSDP、通信开销与大规模训练瓶颈。
- 编译与 Runtime：理解 PyTorch Profiler、torch.compile、CUDA Graph 与运行时优化。
- 推理系统：掌握 Continuous Batching、KV Cache、推测解码、PD 分离与 MoE 推理。

## 课程目录

建议按照第 1 课到第 28 课学习，再完成 8 个综合项目。

### 模块一｜性能工程方法论（01—04）

先建立指标、全栈视角与诊断框架，知道性能问题应该从哪里开始查。

- 第 1 课：AI Systems Performance Engineering 概述
- 第 2 课：AI 系统性能指标体系
- 第 3 课：现代 AI 系统全栈架构
- 第 4 课：DeepSeek 案例——软件优化如何突破硬件限制

### 模块二｜GPU 硬件与系统（05—09）

从 GPU 微架构、显存与低精度计算，扩展到多卡互联和容器化运行环境。

- 第 5 课：GPU 架构深度解析
- 第 6 课：GPU Memory 体系优化
- 第 7 课：Tensor Core 与低精度计算优化
- 第 8 课：NVLink、NVSwitch 与 AI 集群互联
- 第 9 课：Linux、Docker、Kubernetes GPU 性能优化

### 模块三｜CUDA 与高性能算子（10—14）

进入线程模型、访存优化、性能分析、算子融合与 Triton Kernel 开发。

- 第 10 课：CUDA 编程模型
- 第 11 课：GPU Memory 访问优化
- 第 12 课：GPU 性能分析方法
- 第 13 课：Kernel Fusion 与高性能算子开发
- 第 14 课：Triton Kernel 开发

### 模块四｜分布式训练与通信（15—18）

把模型并行、通信原语、NCCL 调优和 FSDP 放进同一套系统模型。

- 第 15 课：大模型分布式训练体系
- 第 16 课：NCCL 深度优化
- 第 17 课：GPU 通信性能优化
- 第 18 课：FSDP 与超大模型训练优化

### 模块五｜PyTorch Compiler 与 Runtime（19—22）

从性能分析到图编译、CUDA Graph 与 Runtime，理解框架如何驱动硬件。

- 第 19 课：PyTorch 性能分析体系
- 第 20 课：torch.compile 深度解析
- 第 21 课：CUDA Graph 与 Runtime 优化
- 第 22 课：AI Runtime 优化思想

### 模块六｜LLM 推理系统（23—28）

覆盖调度、缓存、推测解码、PD 分离和 MoE，搭建现代推理优化全景图。

- 第 23 课：LLM 推理系统架构
- 第 24 课：Continuous Batching 与 Scheduler 优化
- 第 25 课：KV Cache 性能优化
- 第 26 课：Speculative Decoding 与推理加速
- 第 27 课：Disaggregated Inference 架构
- 第 28 课：MoE 推理与未来 AI Runtime

## 六阶段学习地图

### 阶段一｜建立性能语言

核心任务是掌握指标、Roofline 与全栈执行路径，阶段产出为瓶颈假设清单。

### 阶段二｜理解硬件边界

核心任务是理解 GPU、Memory、Tensor Core 与互联，阶段产出为硬件能力边界表。

### 阶段三｜进入 Kernel 优化

核心任务是学习 CUDA、访存、Profiler、Fusion 与 Triton，阶段产出为优化前后 Benchmark。

### 阶段四｜构建分布式训练方案

核心任务是掌握并行、NCCL、通信与 FSDP，阶段产出为多卡训练方案。

### 阶段五｜深入 Compiler 与 Runtime

核心任务是使用 Profiler、torch.compile 与 CUDA Graph，阶段产出为运行时回归门禁。

### 阶段六｜完成 LLM 推理优化

核心任务是掌握 Batching、KV Cache、PD 分离与 MoE，阶段产出为端到端推理优化报告。

## 实验层级与硬件说明

- Level 0｜CPU / 通用回退：验证性能模型、测量方法和自动化门禁。
- Level 1｜常见 NVIDIA GPU：自动检测可用能力，完成 CUDA、PyTorch 与推理基线实验。
- Level 2｜架构专项：面向 NVLink/NVSwitch、RDMA、MIG、FP8/FP4 等真实硬件，不做伪等价模拟。

## 完成课程后，你将拥有

- 一套能够解释 AI 系统性能问题的完整知识框架；
- 一套从测量、定位、优化到回归验证的标准工作流；
- 8 个可以继续扩展为作品集的实战项目；
- 一份覆盖训练、推理、GPU 与 Runtime 的工程能力地图。

性能数字必须在自己的硬件、软件版本和真实工作负载上重新测量。先让系统可测量，再让每一次优化可证明。
