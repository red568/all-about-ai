# GPU

# Why GPU

1. 并行计算的优势，不要求低延迟，但要求大量并行处理的能力（成百上万个核心简单计算）

2. 深度学习的矩阵计算天然适配gpu并行计算的架构

```Plain Text
GPU 芯片
├── GPC (Graphics Processing Cluster)  ← "事业部"
│   ├── TPC (Texture Processing Cluster)  ← "部门"

│   │   │   ├── Shared Memory  ← 共享内存（SM 内所有线程共享）
│   │   │   └── L1 Cache
│   │   └── SM ...
│   └── TPC ...
├── GPC ...
├── L2 Cache（全局共享）
└── Memory Controller → HBM（显存）

```







# SM

SM（Streaming Multiprocessor）是理解 GPU 架构的关键，所有的线程调度和执行都发生在 SM 层面。

📌 关键点：SM 是资源分配的最小粒度。当你编写 CUDA Kernel 时，一个 Thread Block 会被调度到一个 SM 上执行。SM 内的寄存器、共享内存等资源由这个 SM 上的所有 Thread Block 共同分配。

# Wrap

GPU 不是一个线程一个线程执行的，而是以 Warp（线程束）为单位，32 个线程锁步执行同一条指令。这就像军队齐步走——32 个士兵听同一声号令，迈出同一只脚。



这种执行模式叫做 SIMT（Single Instruction, Multiple Threads），是 NVIDIA 对 SIMD 的扩展。

⚠️ 注意：如果 Warp 内的线程遇到分支（if\-else），走不同分支的线程会被 掩码（mask），导致部分线程空转。这就是所谓的 Warp Divergence，是 GPU 编程中需要极力避免的性能杀手。


















# DRAM和SRAM

DDR 和 HBM 都是 **DRAM（动态随机存取存储器）**，也就是“内存”的一种，但它们的定位、结构和用途差别很大。

## DDR 是什么（cpu内存）

**DDR = Double Data Rate SDRAM**，中文叫“双倍数据速率同步动态随机存取存储器”。

- 它是目前最通用的内存标准，常见于电脑、服务器。
    
- 我们常说的 **DDR4、DDR5 内存条**就是它。
    
- “双倍数据速率”指它在时钟信号的上升沿和下降沿都传输数据，所以比早期 SDRAM 快一倍。
    
- 手机里常见的 **LPDDR** 是 DDR 的低功耗版本。
    
- 特点：**容量大、成本相对低、通用性强、可插拔/可扩展**。
    
- 用途：CPU 的主内存，程序运行时数据主要放这里。
    

简单说，DDR 是“电脑主内存”，负责大容量、通用计算。

## HBM 是什么（gpu显存）

**HBM = High Bandwidth Memory**，中文叫“高带宽内存”。

- 它也是 DRAM，但不是做成普通内存条，而是把多层 DRAM 芯片垂直堆叠起来。
    
- 通过 **TSV 硅通孔** 连接各层，再通过 **硅中介层** 和 GPU、AI 加速器封装在一起。
    
- 它的接口非常宽，比如 1024 位、2048 位，而普通 DDR 内存条通常是 64 位。
    
- 因为“路很宽”，所以即使频率不是特别夸张，总带宽也能达到 **数百 GB/s 到 TB/s 级**。
    
- 特点：**带宽极高、功耗较低、体积小，但成本高、容量相对小**。
    
- 用途：高端 GPU、AI 训练/推理芯片、HPC 超算，例如 NVIDIA H100/B200、AMD Instinct 等。
    

简单说，HBM 是“贴在 GPU/AI 芯片旁边的超宽高速公路”，专门解决算力强但内存带宽不够的问题。

## DDR和HBM核心区别

| 维度   | DDR                   | HBM              |
| ---- | --------------------- | ---------------- |
| 定位   | 通用主内存                 | 超高带宽内存           |
| 形态   | 内存条/颗粒                | 多层堆叠，封装内         |
| 连接方式 | PCB 走线，内存插槽           | 硅中介层、TSV         |
| 位宽   | 通常 64 位/通道            | 1024 位、2048 位等   |
| 带宽   | 单通道几十 GB/s，多通道上百 GB/s | 单堆栈可达约 1 TB/s 以上 |
| 容量   | 很大，可到 TB 级            | 相对小，常见几十 GB      |
| 成本   | 较低                    | 很高               |
| 典型用途 | CPU 主内存、服务器、手机        | GPU、AI 加速器、HPC   |


## SRAM 

**SRAM = Static Random Access Memory，静态随机存取存储器**。它也是一种易失性内存，断电后数据会丢失，但和 DDR/HBM 走的路线完全不同。

- **“静态”**：只要不断电，数据就能稳定保持，**不需要像 DRAM 那样定期刷新**。
    
- **结构**：典型 SRAM 单元由 **6 个晶体管（6T）** 组成，用两个交叉耦合的反相器锁存 1 bit。
    
- **速度**：非常快，访问延迟通常只有几纳秒甚至更低，CPU 缓存 L1 常常几个时钟周期就能访问。
    
- **缺点**：每个 bit 占的晶体管多，**面积大、密度低、单位成本高**，所以容量做不大。
    
- **功耗**：不需要刷新，但先进工艺下漏电不可忽视；整体上适合做小容量高速缓存。
    
- **用途**：CPU/GPU 的 L1/L2/L3 缓存、寄存器文件、GPU 共享内存、AI 加速器片上缓存、FPGA Block RAM、嵌入式芯片等。

DDR 和 HBM 本质上都是 **DRAM**，而 SRAM 是另一类 RAM。

| 维度     | SRAM          | DRAM（DDR/HBM）   |
| ------ | ------------- | --------------- |
| 存储单元   | 通常 6T 锁存器     | 1T1C，一个晶体管+一个电容 |
| 是否需要刷新 | 不需要           | 需要定期刷新          |
| 速度/延迟  | 极快，低延迟        | 较慢，延迟高          |
| 密度     | 低             | 高               |
| 成本     | 高             | 低               |
| 容量     | 小，常见 KB～几十 MB | 大，可到 GB～TB      |
| 典型用途   | CPU 缓存、片上缓冲   | 主内存、显存          |
